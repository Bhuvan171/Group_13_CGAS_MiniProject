# Assignment non-overlap record

The original assignment PDFs are stored under `references/assignments/`. They are course evidence and should not be treated as current implementation instructions.

## Assignment 1 already covered

- scraping 10,000 recipes from sources other than RecipeDB;
- extracting ingredient names using named-entity recognition;
- storing recipe-ingredient relations;
- counting unique ingredients and frequencies;
- recipe-size distribution and average recipe size;
- cumulative recipe-size distribution;
- ingredient frequency-rank distribution;
- short nutrition, food-technology, and computational-gastronomy written questions.

## Assignment 2 already covered

- frequent itemset mining on recipes;
- one-, two-, and three-item sets;
- support and confidence;
- size-controlled random cuisines;
- inverse-transformation random cuisine generation;
- size- and ingredient-frequency-controlled random cuisines;
- recipe-size and frequency-rank comparison plots.

## Course-slide themes that should not become copied deliverables

- ordinary food-pairing analysis based on shared flavour compounds;
- assignment-style random-cuisine controls;
- basic recipe-size/frequency distributions;
- a generic cuisine-analysis library reproducing lecture exercises;
- FlavorDB descriptive counts without a new research question.

## Why Sustainome is distinct

Sustainome uses exact food-code integration, life-cycle environmental indicators, nutrient-profile geometry, Pareto analysis, graph-based substitutions, constrained basket optimization, and uncertainty/counterexample analysis. None of these is a repackaging of the two assignments.

Some basic descriptive plots may appear during quality control, but they are not deliverables and should not be presented as the project contribution.
